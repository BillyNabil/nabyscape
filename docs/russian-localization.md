# Русская версия NabyScape 2.26.1-ru.1

Установлена и запущена 9 ноября 2026 года. Открыто окно «NabyScape · Настройки»; русские разделы и подписи проверены в установленном приложении.

- 3438 уникальных переводов: настройки и подсказки, встроенные виджеты, уведомления, ИИ-помощник и голосовые функции, установщик и удаление.
- Самостоятельная сборка Windows x64: 582 проверки пройдены, 0 ошибок.
- Проверена регистрация всех 58 разделов примеров настроек; 5 проверок плана удаления пройдены.
- Созданы и просмотрены снимки русских настроек, голосовой настройки и установщика в отдельном профиле.
- Выполнен независимый просмотр изменений; исправлены проверки состояний, кнопка отмены звукового теста и восстановление доступа к микрофону.
- SHA-256 установленного EXE совпадает с проверенной сборкой: `2E7CFD087040765C78CEA6191DF50364A0A32BD125AC636C0B0D50BE4B551504`.
- Из существующих значений настроек изменён только язык. Появился новый параметр текущей исходной версии ExternalNotificationQuietHours=false; в прежнем профиле он отсутствовал. Пользовательское содержимое сохранено.
- Прежние файлы программы сохранены в папке «NabyScape-до-русификации». Исходные настройки — в `%LOCALAPPDATA%\NabyScape\settings.before-russian-build.json`.
- Обновление оригинальной сборкой отключено, чтобы сохранить русификацию.

Форк: https://github.com/MrBogomoll/nabyscape
GitHub Release не опубликован. Установщик и portable ZIP сохранены рядом с этим отчётом.

Названия продуктов, моделей, файлов, тексты пользователя и ответы сторонних сервисов сохраняют исходный язык. Для платных API и голосовых загрузок потребуются собственные подключения; такие запросы во время проверки не выполнялись.

Перекрытие кнопок окон при разделённом экране — отдельный следующий этап; поведение расположения панели на этом этапе не менялось.
