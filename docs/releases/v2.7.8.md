# NabyScape 2.7.8 · Compact media controls

The compact music panel replaces its permanently visible media selector and Windows volume slider with two small footer actions.

- Choose the source name to select an active Spotify, browser or other Windows media session. The current session has a checkmark; an empty state explains when no sessions are available.
- Choose the speaker and percentage to adjust the original Windows volume slider or mute. The mixer icon opens the existing mixer; the header chevron opens output devices and microphone controls.
- Popovers stay inside the music surface and do not resize the dock or move its transport, waveform, timeline or lyrics.
- Enter or Space opens a focused footer action. Tab cycles through the open controls. Escape or a click outside dismisses the popover; choosing another widget closes it too.
- Long source lists scroll within the popover. Cursor following pauses while it is open, and Reduce Motion skips its entrance animation.

The classic inline layout and independent media/volume widget switches remain supported. Sources are existing Windows media sessions; this menu does not launch applications. Personal preferences and provider credentials are unchanged.
