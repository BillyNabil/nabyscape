# NabyScape 2.18.1 · compact idle dock

When media is paused or unavailable and no voice, countdown or notice needs the closed dock, its contents become a clock, compact weather icon/temperature and the existing optional Naby character. The idle width is measured from these contents and animated with the existing surface motion. It never overwrites the saved active width or position. Clock/weather/character preferences remain respected. Active voice, music, focus/timer sessions, feedback and notices retain the normal presentation; tucked geometry keeps its configured width and black edge behavior.

Paused media sessions no longer leave the closed waveform's dotted baseline or artwork visible. Voice has a concise status when it owns the closed header. Secondary media activity satellites also require playback, preventing paused sessions from displacing the idle content or countdown.

The weather indicator reuses existing location, units, service/cache and static vector artwork. It refreshes through the existing clock heartbeat/cache policy without adding a polling timer. Missing/disabled weather, a location mismatch, cached data older than two hours or insufficient width remove the indicator; the clock and optional Naby remain. Weather failures do not create idle notifications. Naby retains its existing subtle animation and Reduce motion behavior.

Validation: source review, whitespace checks and Release compile/publish/package metadata only. No tests, UI automation, screenshots, weather endpoint trials, microphones, inference or provider requests were run, as requested. Actual visual alignment and transitions remain unverified at runtime.
