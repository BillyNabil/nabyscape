# NabyScape 2.8.0 · Flexible dock, ambience and weather

Local implementation build. Automated tests and UI diagnostics were not run, as requested. Compilation and publishing only.

- Closed and tucked dock surfaces return to black immediately, including album tint and ambient audio demand. Opening a panel restores its configured appearance.
- Ambient light supports a single dominant album color, two-color cover blend, accent, one custom color or a custom pair. New direction, balance, reach and softness controls complement intensity, motion and audio response; spread extends to 250%. Layout exports retain these settings.
- Spotify's footer glyph uses a bounded vector canvas scaled to the actual icon slot.
- Layout → Dock placement offers Top, Bottom, Left, Right and Floating. Side/bottom docks use the display work area, expand inward and tuck toward their chosen edge. Content stays upright. Dragging switches to Floating; Escape restores the original placement.
- Weather is an individual content widget with city search, Celsius/Fahrenheit, day/night condition artwork, a six-hour outlook, daily high/low, rain chance, humidity and wind. Choose a city in the widget; no GPS or IP location lookup is used.
- Weather data is fetched from Open-Meteo only after a location is configured and its widget is visible. Results cache for 20 minutes, failed automatic attempts back off, and hidden artwork stops its retained idle clock. Location and cache stay out of exported layout profiles.

Weather sources: [Forecast API](https://open-meteo.com/en/docs), [Geocoding API](https://open-meteo.com/en/docs/geocoding-api). The widget includes source attribution.

Existing data and preferences retain their formats; the installer is built from source and contains no personal provider credentials. GitHub publication is separate.
