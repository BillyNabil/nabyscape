# NabyScape 2.7.4 · Timer & Focus

Local build. This candidate has not been pushed or published to GitHub.

Timer and Focus now have one primary action: **Start → Pause → Resume**. Starting a session replaces Start immediately, so pausing no longer accidentally restarts the countdown. Reset is a separate action and becomes available after a session starts.

The familiar two-column layout has clearer time displays, thin progress tracks, aligned duration fields and readable session states. Narrow panels keep the existing stacked arrangement. Both compact and classic layouts use the same countdown control.

- Idle timers preview the selected duration. A timer started elsewhere displays its actual duration when opened here.
- Duration fields lock while a session is running or paused. Reset makes them editable again.
- Invalid durations show an inline hint and disable Start; valid drafts and text selection survive shared updates.
- Focus keeps its configurable work and break durations and shows the current break state.
- Countdown views subscribe to the existing heartbeat only while visible and ignore unrelated media/audio updates.

Absolute deadlines, sleep/resume behavior, completion notifications, sound preferences and stored data retain their existing behavior. The visual refinements from the local 2.7.3 build are included.
