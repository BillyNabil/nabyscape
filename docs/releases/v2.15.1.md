# NabyScape 2.15.1 · local UI candidate

Chat/Voice navigation now uses a dedicated chat icon and clearer selected-mode styling. AI settings, Voice settings and Connect Hermes use larger action cards with descriptions, consistent spacing and hover feedback. Voice shows error/status text only when attention is needed, hides an empty user transcript and switches the primary microphone icon to Stop during a conversation.

Conversation presets remain removed. Local custom-model support and existing user instructions are preserved. Compiled and packaged without UI automation, speech trials or inference tests, as requested.
