# NabyScape 2.27.0 verification

On 14 November 2026, the local Windows 11 x64 release executable, built with the .NET 10.0.404 SDK, passed **all 613 logic tests**, together with the Settings scene registry (every Settings section has a registered example) and uninstall-plan checks.

New tests cover:

- **Theme:** default and older profiles keep the classic dark look and black closed dock; Follow Windows is the only choice that reads the Windows app mode; Light substitutes only the default dark colors; light ink stays readable (WCAG AA against the light base); returning to Dark restores the original brushes; content attached to a light surface re-maps without relying on WPF's Loaded event, while dark artwork cards such as the weather sky keep light ink.
- **Collapsed island:** the collapsed color and opacity paint only the closed surface; reset, layout profiles, undo and older backups cover the new keys.
- **Languages:** every catalogued string has a Russian, Ukrainian, Korean, Spanish and Indonesian translation with matching `{0}` placeholders, and language codes normalize safely.
- **Voice:** the echo gate mutes the microphone while assistant audio is queued or playing, holds a short tail and resumes; a stalled output never keeps it shut; Gemini Live uses `NO_INTERRUPTION` in half-duplex and barge-in only when chosen; OpenAI Realtime and Gemini Live both pause and resume uploads around a reply.
- **Media:** timeline states (none, read-only, seekable), position interpolation between sparse player updates, Auto source following the app that starts playing while a hand-picked source stays pinned, browser exclusion, and loopback capture retry backoff.
- **Weather:** refresh scheduling (fresh, stale, failed with backoff, resume nudge, unused), honest status and age labels, next hours following the forecast location's clock, downloads that finish after their view closes, and use only where Feature usage shows weather.
- **Closed dock clock:** position normalization and round-trips, Automatic unchanged, centered layout math for notch and pill shapes, and closed-width bounds and search.

Isolated showcase captures (no personal profile) were reviewed in Light, Dark, and Dark with a custom collapsed color: the closed dock, hover preview, media, weather, system, notes, tasks, file shelf, calendar, focus and every Settings page are readable in Light, and Dark matches 2.26.1. The Focus duration fields clip two-digit values in both themes, as they did before this release.

Not validated: Telegram Desktop, Windows 10 loopback capture and Gemini Live/OpenAI Realtime were not exercised against the real apps and services; their behaviour is covered by logic tests only. Russian and Ukrainian strings await native-speaker review. Public packages are rebuilt from the tag by GitHub Actions, which verifies both PE architectures, executable identity, WinGet metadata, asset hashes and all nine notices.
