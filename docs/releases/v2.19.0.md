# NabyScape 2.19.0 · guided AI setup and consistent controls

AI settings are organized into Overview, Chat, Voice, Hermes and Advanced. Overview separates a saved provider from a connection that has returned a chat response, and a selected speech configuration from installed speech files. A contextual button enables AI, opens chat setup, checks the saved chat connection or opens chat. Model downloads, microphone activation and network checks remain explicit user actions. Hermes server discovery is metadata only; a chat check is an actual agent message. A completed normal chat or local-voice reply also confirms its chat connection without an extra request.

Connection checks have cancellation and visible busy states. Their in-memory results match the saved provider identity, endpoint, protocol and chat model; draft edits are labeled and do not verify a saved connection. Saving a provider or forgetting its key invalidates its previous check. Hermes credentials are also separated when its profile path changes. Automatic speech setup offers Open voice mode once the selected pack is installed and a chat model is configured. Opening voice with incomplete setup leads to Voice settings. Settings search reveals the appropriate AI category before focusing its control.

Stopped chat and attachment work no longer overwrites the state of a stopped or replaced session. Local typed voice turns use both caller and session cancellation, and closing voice cancels capture, playback and managed engines before waiting up to eight seconds for the active turn to unwind. Recognition timeouts are reported rather than silently returning to listening. Wake setup checks speech readiness. Chat history snapshots are reused until messages change; chat, voice and dock state refreshes are coalesced on the UI dispatcher. Hidden model setup pages pause progress refresh work. Hidden chat views release transcript visuals and rebuild them with their saved scroll position when reopened. Unchanged motion preferences no longer refresh the character repeatedly. These changes are source-based improvements, not measured performance claims.

Settings and AI now share button sizing and corners, input outlines, expander behavior, card surfaces, selected-control colors and keyboard focus treatment. Chat has a clearer empty state and a contained status message. Voice offers Set up voice or Try again when appropriate. The black idle dock, date typography, configured dock size, existing widgets, attachments and provider protocols are preserved.

Validation: source review, whitespace checks, Release build/publish and installer metadata only. No unit tests, UI automation, screenshots, microphone access, model inference, provider/Hermes requests or runtime benchmarks were run during development, as requested. Multi-PC behavior, visual alignment, audio shutdown and measured performance still require runtime validation before a production-readiness claim.
