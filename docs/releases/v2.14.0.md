# NabyScape 2.14.0 · local candidate

Local speech setup now offers hardware profiles for CPU with 8/16/32 GB RAM and NVIDIA with 2/4/6/8+ GB VRAM. Settings and guidance are English, and new voice configurations default to English. Recommendations consider available memory, thread count, supported language and Light/Balanced/Quality preferences.

Added installable Moonshine v2 tiny/base English and base Spanish, Qwen3-ASR 1.7B INT8 community ONNX conversion, Whisper Q5/Q8 packages, KittenTTS nano v0.8 INT8 and Supertonic 3 INT8. Existing Qwen3-ASR 0.6B, Whisper, Kokoro, Piper and Windows voices remain available. TTS uses CPU across all GPU profiles; it does not need artificial VRAM tiers. Quantized Whisper is not advertised as a new model generation.

Install & use downloads verified packages, activates the selection and makes it available to Voice mode. Engines start only with Start conversation and close with End conversation. The model library shows descriptions, sizes, memory fit and source/license links. Supertonic OpenRAIL-M terms are separate from the app license.

Compiled and packaged without tests, microphone/speaker trials, provider requests, model inference or hardware benchmarks, as requested. Runtime installation and international/native CLI encoding remain unvalidated. See [local voice](../local-voice.md). This candidate is local; it has not been pushed or published.
