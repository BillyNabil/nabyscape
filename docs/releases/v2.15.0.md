# NabyScape 2.15.0 · local candidate

Users can bring existing ASR/TTS model files into voice setup. Supported formats include Whisper GGML, Sherpa-ONNX Qwen3-ASR INT8/Moonshine v2 and Piper/Kokoro/Kitten/Supertonic voices. Browse or paste paths, check the file structure, prepare only missing native engines and use the selection in a voice session. Files remain in place. Installed packs and Windows voice can be mixed with custom models. Unsupported exports can use an external localhost speech service.

Removed Friendly conversation, Language practice and Focus check-in presets. Chat and Voice now share a mode control and connection bar, grouping AI/Speech setup and Hermes. Voice has a single primary Start/End conversation control and explicit microphone status. User-written assistant instructions are preserved.

Compiled and packaged without tests, UI automation, microphone/speaker trials or model inference, as requested. File checks are structural, not proof of inference compatibility. Imported models have no verified memory/quality budget, and native CLI encoding limitations remain. See [local voice setup](../local-voice.md). This candidate is local and has not been pushed or published.
