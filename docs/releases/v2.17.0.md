# NabyScape 2.17.0 · local voice and navigation candidate

Image paste now owns the composer's Paste command rather than relying on the TextBox Pasting event, which is skipped for image-only clipboards. Ctrl+V and the normal Paste menu accept PNG clipboard streams, bitmap images, copied files and text. Clipboard access has bounded retries, normalization runs outside the UI thread, and Copy image supplies both PNG and bitmap formats.

Optional Hey Naby wake listening uses Windows' installed SAPI recognizers through Microsoft System.Speech 10.0.13. Wake word is off by default and has explicit save/apply opt-in, custom phrases, recognition language, confidence and pause/resume controls. Local wake detection hands off the microphone before starting configured local/realtime voice. The island/tray expose microphone state. End conversation can re-arm wake after teardown/cooldown; global Stop, Hide, lock, sleep and quit pause microphones. Missing recognizers/configuration and device failures have actionable status, with no automatic failure retry loop.

Tool-capable direct chat, local voice and realtime providers can list/open enabled widget pages through two bounded navigation tools. No widget mutation or general computer control is restored. A local stdio MCP connector and Windows/WSL setup exports provide these tools to Hermes and other local MCP clients. The bridge uses a current-user-only named pipe and opens no network port. Tool execution validates name, arguments, enabled pages and cancellation before UI dispatch.

Validation: source review and Release compile/publish/package metadata only. No tests, UI automation, clipboard trials, microphones, wake recognition/emulation, inference, provider calls, MCP handshakes or live Hermes requests were run, as requested. Clipboard behavior, recognizer availability/accuracy, Windows audio-device handoff and real model/MCP behavior remain unverified at runtime. System.Speech licensing is embedded and installed with the app. See the [AI guide](../assistant.md) for setup and limits.
