# NabyScape 2.7.2 · Lyrics beside your music

This release includes the media and interaction updates since v2.6.3, plus the compact-waveform and clipboard fixes verified locally in 2.7.1 and 2.7.2.

## Added

- Opt-in synced Spotify lyrics with Slide, Focus and Karaoke presets, timing offset, Retry and local LRC import. Lyrics open in a right column when space allows, with a stacked fallback on narrow screens. Hiding them restores the saved panel width.
- A shared, measured 25-band output spectrum, fast attack/release and adjustable sensitivity. Selected-app amplitude history remains available. The closed waveform now uses up to 104 × 22 DIP and thicker bars, making quieter bands readable.
- Minimal dot navigation, with named controls and keyboard access.
- Separate Shelf, Notes, Tasks, Clipboard, Calendar, Keep awake and Clean links panels in Content widget ordering. Existing tool preferences and data migrate in place.
- Move and resize grips for the closed island, hover and open panel, with keyboard alternatives and Escape to cancel. Automatic or manually sized panel height.
- Editable Focus and Break durations in the panel, plus Chime, Bell, a custom WAV or Off for completion feedback with separate volume.
- An option to suppress automatic browser-media previews, including YouTube hover-playback sessions.

## Improved

- Naby chat has a simpler composer, inline voice/screen controls and less header clutter. Provider configuration remains in app Settings.
- Clipboard history has its own bounded scrolling viewport. Headers and navigation stay still, fast trackpad input accumulates, and returning to the panel restores the list position. Wheel over navigation changes panels; horizontal gestures can leave the list.
- More consistent Media padding, independent hover/panel sizing and editor draft/selection preservation during resource changes.

## Before you enable lyrics or AI

Lyrics lookup sends track title, artist and duration to LRCLIB. Availability depends on the track and service. Karaoke uses line timing, not word timestamps. Imported LRC files and lyric caches stay in memory for the app session.

Frequency spectrum uses WASAPI output loopback, so other apps sharing the output can affect the display. No audio samples are saved. Amplitude history uses the selected app's level.

AI remains optional and requires your own provider configuration. No API keys, saved providers, conversations, Notes or clipboard history are bundled. Keys remain in Windows Credential Manager on your PC. Microphone, screen sharing and reviewed actions remain explicit session choices.

The Windows x64 installer is currently unsigned; SmartScreen may still display a warning. No signing or WinGet acceptance is claimed by this release.

## Downloads

- `NabyScape-win-x64-Setup.exe` — per-user installer, bundled .NET runtime.
- `NabyScape-win-x64-Portable.zip` — extract the entire archive, then run the app.
- `NabyScape-Notices.zip` — third-party license notices.
- `SHA256SUMS` — SHA-256 hashes for these three files.

Existing installations retain their saved layout and local content. Starting with Windows remains an explicit preference. Back up important local data before an upgrade.
