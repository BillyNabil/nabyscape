# 2.12.0 · Automatic local speech setup

Local update; not published to GitHub.

- Scan CPU, available physical memory and graphics hardware locally; use NVIDIA's installed utility for driver and VRAM information when available.
- Suggest a supported Whisper model using available-memory budgets. The user can select a different model, speaking language and optional NVIDIA acceleration.
- Install & use downloads pinned, checksum-verified native engines and weights with progress, cancellation, error reporting and retry. A missing Microsoft C++ x64 prerequisite uses Microsoft's installer and may need Windows administrator approval.
- Native Whisper tiny/base/small/large-v3-turbo, Windows speech, and Piper voices for Indonesian, English and Spanish. Python and external ASR/TTS servers are unnecessary in automatic mode. Existing realtime and advanced external-server paths remain available.
- Start installed engines with the voice session and shut them down when it ends. Native children belong to a Windows job with kill-on-close, so exiting the app releases models too. NVIDIA startup failure falls back to the installed CPU engine.
- Installing/switching a managed speech pack preserves chat and external-server preferences. Chat replies continue to use the user's separately selected chat provider/model.

Windows x64 AVX2/FMA is required for the automatic native packs. Recommendations are heuristics, not measured speed or memory guarantees; language and dataset terms vary by TTS voice. Optional assets are outside the initial app/installer and are not downloaded on startup.

Compilation/package only at the user's request. No automated tests, speech-engine execution, model-weight downloads, microphone/speaker trials, chat-provider requests or performance benchmark were run. Native archive metadata, source interfaces and pinned checksums were inspected. End-to-end automatic installation and inference remain untested.
