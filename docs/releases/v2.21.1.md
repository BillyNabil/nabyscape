# NabyScape 2.21.1 — Naby, live lyrics and a clearer setup

This cumulative release brings the updates developed since public 2.10.1 into one Windows release.

## Downloads

Choose **x64** for Intel/AMD 64-bit PCs or **ARM64** for native Windows on ARM. Each architecture has a Setup executable and portable ZIP. The same package targets Windows 10 build 19041+ and Windows 11; Windows 10 22H2 is recommended over older Windows 10 builds. OS/.NET support follows Microsoft's lifecycle. The .NET runtime is included. Packages are unsigned and install for the current Windows user. `SHA256SUMS` and the dependency notices accompany the release.

## Music and everyday use

- Closed media display offers Waveform, Live lyrics, Song title and None. Long lyrics transition as readable phrases. Hover keeps playback controls. None leaves music running and lets idle/focus content show.
- Lyrics use track metadata and timing from compatible Windows media sessions, including Spotify, YouTube Music and Apple Music. Coverage and sync vary by track/player; local timed LRC import is available.
- Media controls, source menus, voice panels, compact weather and focus/stopwatch coexistence receive layout fixes. Idle, None and tucked states suppress runtime ambience while preserving preferences.
- Resource controls let users keep only the widgets/background integrations they need. Audio resources and offscreen previews reduce their work when unused; there is no fixed RAM guarantee.

## Naby AI and voice

- Formatted chat, pasted images, image/video/PDF attachments and compatible image replies. Capabilities depend on the selected provider and model.
- Provider connection checks, manual model IDs, model lists and visible saved/ready/error states. Keys stay in Windows Credential Manager.
- Guided Hermes connection. Hermes manages its agent tools and permissions; the former native Actions/Computer switches are removed.
- Realtime voice, local ASR/TTS packs, hardware-based suggestions, imported models, external speech services and model removal. Model downloads are explicit; no API access or model weights are bundled.
- Optional wake word, selectable window/display sharing, widget navigation tools and reactive reply notices. End conversation resumes wake listening when enabled; explicit Stop pauses it.
- Streaming and bounded preview caches reduce response/display overhead. Actual latency still depends on ASR, model/provider, Hermes and TTS.

## Setup, recovery and accessibility

- Skippable Music/Productivity/AI/Custom onboarding, Settings Start here, readiness cards, clearer navigation, save feedback and session-scoped appearance/layout/widget Undo.
- English defaults, partial Spanish/Indonesian interface localization, text-size controls, accessible names, keyboard focus, high contrast and reduced motion.
- Safer configuration writes/backups, private diagnostics, update recovery and device/sleep/network recovery. Automatic update checks/downloads default on; installation/restart remains explicit.
- Refreshed README and the live web3-style website at https://nabyscape.vercel.app/.

## Validation and limits

The release packaging runs logic tests on its native x64 host and verifies both architectures, portable contents, notices, version metadata and SHA-256 checksums. Earlier isolated UI acceptance for this source completed **836 passed, 0 failed**, with targeted follow-up suites documented in [verification-refresh.md](../verification-refresh.md).

Local UI acceptance ran on Windows 11 x64. Physical Windows 10 and native ARM64 execution are not certified by cross-compilation. Automatic native speech packs require an x64 process with AVX2/FMA; ARM64 users can use compatible external local ASR/TTS servers or providers. Live provider acceptance, model quality, microphones/speakers and every physical device transition require the relevant services/hardware. See [production foundations](../production-foundations.md).

## Included 2.21.1 hotfix

The Naby voice page fits its actual dock viewport, including navigation, panel scaling and scroll chrome. Session controls and the Chat/Voice/Options footer stay visible at normal sizes. The avatar yields space before text and controls; short or enlarged views retain bounded scrolling without shrinking accessible text. Existing voice sessions, captions and reactive animations keep their behavior.

Choosing None suppresses runtime ambience on the dock, companion satellite and detached widget previews. Closed idle remains black. Preferences stay enabled so selecting Auto or an app can restore the configured ambience. Settings previews remain usable while None is selected.
