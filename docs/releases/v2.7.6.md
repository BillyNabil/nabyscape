# NabyScape 2.7.6 · Ambient across widgets

Official Windows x64 release. Includes the refinements developed in local 2.7.3–2.7.5 builds; the website is maintained separately.

**Settings → Appearance → Ambient light** now controls light beneath the content on the island, hover pages, mini windows and Settings preview.

- **Show ambient on:** All widgets, Music only, or Selected widgets. The selector includes individual tools, the closed island and AI companion. Grouped panels light up when one of their visible widgets is selected.
- **Light color:** Album cover, Accent color, or Custom color. Album cover follows the selected media session and falls back to the accent without artwork.
- **Intensity / Spread:** set maximum brightness and how far the light reaches upward. The existing dark surface, text and control layout are preserved.
- **Audio response:** Off, Soft, Responsive, or Punchy, with adjustable sensitivity. The glow follows measured audio from the selected media app. It does not listen to the microphone or synthesize beats during silence.
- **Movement:** Still, Breathe, or Drift remains independent of audio response. Still can react to music while staying in place.

New preferences default to **All widgets**, **Album cover**, **Responsive**, and **140% sensitivity**. Existing intensity, spread, movement and master-switch values are kept during upgrade. Reset Appearance and layout export/import include the new controls.

Audio consumers share AudioService's existing 30 Hz sample gate. Ambient alone reads session amplitude without starting output spectrum capture or FFT. Closing mini windows releases their registrations. Paused playback, hidden/tucked surfaces, Reduce motion and Live activity Off stop reactive demand; static color remains available. Settings preview uses this same sampler.

Notification details retain their clean dark surface. Ambient does not open panels, change audio volume, or change Timer/Focus behavior.

## Also included since the previous public release

- **Timer and Focus:** one Start / Pause / Resume action, a separate Reset, clear session states and aligned duration fields. Running and paused sessions lock duration edits until reset.
- **Interaction polish:** more readable controls, vector chevrons, consistent tooltips, hover/press feedback and Off / Subtle / Expressive motion.
- **Notifications:** Lift / Fade / Soft scale entrances, configurable lifetime, scheduled quiet hours, snooze and queue actions. Completion sounds follow quiet hours and snooze.
- **Hermes Agent:** a connection preset for an existing API gateway, isolated chat sessions and backend permission guidance. Naby does not install Hermes; live backend interoperability remains a manual check.
