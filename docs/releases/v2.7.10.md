# NabyScape 2.7.10 · Compact widget refinements

Local build; not yet published to GitHub. Includes the runtime optimizations from 2.7.9.

- Smaller media-source and volume actions open bounded controls below the footer. Playback, timeline and lyrics stay unobscured. Long source lists scroll internally; short screens retain the outer viewport.
- Playback and waveform use the same horizontal center alongside the album cover. Original waveform response, rendering and animation quality are retained.
- Timer and Focus keep the existing circular instruments and state-driven Play/Pause/Resume action. Duration fields now have editable values, minus/plus controls and a consistent vector reset icon. Active sessions lock duration edits.
- Countdown fields allow widget-wheel navigation. Small rounding overflow in side-by-side countdowns no longer steals carousel gestures; stacked content and real long lists retain scrolling.
- Naby's send action sits beside the composer tools, is disabled for empty messages and retains Enter/Shift+Enter behavior. AI Settings remains available in the expandable options; the extra header shortcut and visible keyboard hint are removed.
- Launch uses a thin search outline and cached grayscale application artwork with original transparency. The app picker retains its original icons.
- Tasks uses a readable open count and a compact bordered composer. Completion, deletion, Enter-to-add and draft preservation remain available.
