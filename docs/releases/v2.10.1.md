# NabyScape 2.10.1

Fixes Weather being clipped after its forecast loads. The dock previously kept the height measured while the weather view was empty.

- Recalculate panel height when weather data arrives, when its content size changes, and when the location editor opens or closes.
- Coalesce resize requests and ignore views that have been replaced or left, using the existing panel animation rather than a new timer.
- Correct loading and city-search text encoding.
- Preserve the compact weather design, saved city, temperature units and other user preferences.

Includes the installer, portable ZIP, third-party notices and SHA-256 checksums. The app and installer version is 2.10.1. The existing 2.10 demo remains available in the previous release.

Compilation and packaging completed. Tests and benchmarks were not run, as requested. Existing user data is preserved on upgrade.
