# NabyScape 2.25.0 verification

Local feature verification on 1 November 2026, Windows 11 x64:

- **538 logic checks passed**, including provider routing/parsing, metadata and duration matching, cancellation, language filtering, offline Romaji, preserved timestamps, preference persistence and uninstall-plan isolation.
- **40 targeted UI checks passed**: 11 compact lyrics-menu checks, 12 closed-dock waveform/lyrics fallback checks, and 17 scrolling/lyrics checks. Earlier Power plan/advanced lyrics UI checks also passed (6).
- A live decorated-title lookup for an English sample found 59 timed lines through LRCLIB in 428 ms before language filtering was introduced. This is one measurement, not a latency guarantee for the release.
- Live responses returned timed results from lrc.red, BiniLyrics, BetterLyrics, BetterLyrics Potato, LyricsPlus and LRCLIB. Unison and KuGou returned empty results for that sample. PaxSenix experienced errors/timeouts. Account-key routes and YouTube payload routing were checked with fixtures, not real account credentials.
- The reported Spanish translation was rejected in regression tests despite matching title, artist and duration. A faster Spanish response did not cancel a slower valid Japanese response. A later live lookup for the reported Japanese track found no acceptable result; availability of Japanese lyrics for that track is not claimed.
- Actual offline worker tests converted kanji, preserved English/punctuation, kept timestamped instrumental breaks, restored Original immediately and cancelled pending conversion. The worker exits after conversion; dictionary data is not retained in a background converter process.
- Package validation recomputes hashes, checks x64/ARM64 PE architectures, compares setup/portable executables, verifies WinGet metadata and checks all eight notices in both portable packages and the notice archive. Tagged release assets are built and checked independently by GitHub Actions before publication.

These checks use fixtures and isolated profiles. They do not establish a fixed RAM ceiling, GPU-presented animation FPS, complete live-provider coverage, physical Windows 10 behavior or native ARM64 runtime behavior. No live microphone/speaker or speech inference quality claim is added by this release. Existing settings/models are preserved during local updates.
