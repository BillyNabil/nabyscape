# NabyScape 2.24.0 — simpler dock, responsive previews

- Live lyrics automatically switches to the existing waveform when timed lyrics are unavailable, before the first timed line, or during timestamped blank/instrumental sections. The next vocal line restores the text. Instrumental breaks need markers in the lyric data; NabyScape does not separate vocals from audio. Countdown, voice and notification feedback retain priority, and Reduce Motion remains respected.
- Hover previews construct widget contents when first needed. The lightweight preview shell is prepared after startup paints; contour frames reuse cached monitor placement rather than repeating monitor/DPI discovery.
- Naby's retained eye transforms use a shallower drawing stack while preserving the original geometry, clock timing and animation curves. Local pixel comparisons and performance measurements are documented in [WPF runtime and hover performance](../wpf-performance.md); there is no fixed RAM guarantee.
- Settings correctly completes closing after Discard in an unsaved-provider prompt, releasing the window and its temporary subscriptions.
- Removed Activity Satellite (two activities side by side) and the Activities routine builder from the UI, Settings and runtime. Standard shortcuts, Timer/Focus, Keep awake and automatic previews remain available.
- The application uses one WPF host. Install upgrades remove only known retired UI/Core host files from previous local experiments. Retired renderer, Satellite and routine preferences are ignored on load and removed on the next normal save, while unrelated/unknown preferences are preserved. Legacy routine files are retained as inactive user data.

## Install and update

Choose the x64 installer for Intel/AMD PCs or ARM64 for Windows on ARM. Both architecture-specific packages target Windows 10 build 19041+ and Windows 11; a separate Windows 10 installer is not required. Portable ZIPs, dependency notices and SHA-256 checksums accompany the installers.

Upgrading preserves existing preferences, provider credentials and model storage. The complete recommended first-install defaults, installation folder chooser and managed-model cleanup options remain available. The updater discovers this release through GitHub's latest published release.

Installers are unsigned. Windows 11 x64 is exercised locally; physical Windows 10 and native ARM64 execution have not been validated. ARM64 packages are cross-compiled and structurally checked. Managed local speech packs have separate x64/AVX2/FMA requirements; compatible external speech servers remain an option on ARM64.
