# NabyScape 2.16.0 · local chat attachments candidate

Chat now accepts attachments through a paperclip, drag-and-drop and clipboard paste. Compact removable previews keep files near the composer; a file-only message can be sent without typed text. Input supports images, PDF, video, audio on supported Gemini models, text/code and extracted DOCX/PPTX/XLSX/ODT contents.

Provider adapters send native PDFs and Gemini video data where supported. Hermes receives the first 12 PDF pages or 8 sampled video frames as images because its API rejects non-image files. Sampling limits and missing video audio are explicit. Image replies render as native cards with enlarge, Copy image and Save. Supported forms include Markdown URLs, structured parts, Gemini inline data, Chat Completions image arrays and Responses image-generation results. Provider settings include an optional Image replies capability; Hermes manages its own image tools.

Files remain in session memory and are sent only on Send. Attachments use bounded file sizes, text extraction, native Windows previews, capped media downloads and the existing destination checks. Credentials do not follow image links to third parties, redirects are disabled, and returned local filesystem paths are never automatically read. No new packages or background model services were added.

Validation: source review and Release compilation/package checks only. No unit tests, UI automation, clipboard trials, PDF/video sample conversion, microphone capture, inference, paid provider calls or live Hermes requests were run, as requested. Provider, model, codec and generated-image behavior still require real-use verification. See [the attachment guide](../assistant.md#attach-files-and-receive-images) for limits and setup.
