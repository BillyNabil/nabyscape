# NabyScape 2.7.3 · Visual polish

Local candidate. Public downloads remain on 2.7.2 until a release is explicitly published.

This update refines the existing compact interface. Widget grouping, dot/icon/text navigation, control positions, nine Settings categories and saved preferences remain as before.

- Softer input outlines distinguish hover, editing and disabled states without changing the text inset or editor size.
- Dropdown chevrons and expandable sections use clean vector strokes. Keyboard focus remains visible, while focused dropdown text stays at full opacity.
- Tooltips share the app's dark surface and wrap long hints within a bounded width.
- Primary button labels and selected Settings categories have clearer emphasis. Hover and press feedback retain text contrast.
- Supporting text is slightly clearer; Naby responses have more readable line spacing within the existing conversation layout.
- Settings illustrations retain their placement and content, with finer edges, smoother sample waveforms and accurate notch/pill contours.

The live waveform algorithm, sampling, island animation timings, data storage and provider behavior are unchanged. No settings migration or navigation preference change is involved.
