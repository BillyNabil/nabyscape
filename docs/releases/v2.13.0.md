# NabyScape 2.13.0 · local candidate

- One Voice mode entry in chat; removed the duplicate composer microphone.
- Windows native picker for sharing an application window or entire display, with source preview, cancellation and independent Stop sharing.
- Removed Naby local Actions/Computer, widget tools and mouse/keyboard injection. Hermes manages agent tools and permissions.
- Guided Hermes connection: gateway instructions, profile routing, server key, metadata check, advertised agent selection and error messages.
- Hardware recommendations now include language and priority, pack memory/download budgets and a model comparison list. Added Qwen3-ASR 0.6B INT8 (2026) CPU recognition and native Kokoro v1.1 INT8 English speech alongside Whisper/Piper and Windows voices.
- Automatic installation downloads pinned, SHA-256-verified packages only after Install & use. Native engines are session owned; Qwen/Kokoro load on demand. No model weights are bundled in the app.

Compiled and packaged locally without running tests, UI automation, provider/agent requests, microphone/speaker trials or inference, as requested. Runtime capture, installation and speech latency are not validated. See [Hermes setup](../hermes.md) and [local speech](../local-voice.md). This candidate has not been pushed or published to GitHub.
