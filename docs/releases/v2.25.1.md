# NabyScape 2.25.1 — more ways to follow the music

- A compact **Lyrics** popover replaces the scattered search/import buttons. Choose Automatic, one of 14 providers, Retry, Local LRC, or an optional compatible API. The popover scrolls independently and keeps the dock open while you use it.
- **Automatic** cleans presentation labels from browser metadata, checks title/artist/duration, and searches at most two public sources at once. A matching result cancels remaining requests. Successful lyrics remain in a bounded memory cache across dock collapse/reopen.
- Automatic accepts detected **English, Japanese and Korean**, skipping other detected languages such as Spanish translations even when metadata matches. Rejected results do not cancel another provider's valid result. Language detection is offline; very short or ambiguous text can still be misidentified. Manual sources and local imports remain explicit choices.
- **Lyric text → Original / Japanese Romaji** preserves the original timestamps and instrumental markers in the panel and closed dock. The bundled Japanese dictionary runs in a short-lived offline worker after Romaji is selected. Names, uncommon words and creative readings can differ from the generated pronunciation. This is a reading aid, not translation.
- Provider adapters support TTML and QQ/QRC timing as well as LRC. BiniLyrics follows bounded redirects only between trusted HTTPS provider hosts. Lyrics requests have size/time limits and cancel on track changes or menu closure. Provider access failures no longer escape Automatic fallback.
- Enable the optional **Power plan** widget in **Settings → Widgets & tools** to select a Windows power scheme. Changes require Apply; the closed widget does not poll. The plans available depend on Windows and the device.
- Volume preview dragging reuses the maintained audio endpoint instead of re-enumerating output and microphone devices on each movement. Identical volume notifications no longer cause redundant global UI updates.

## Provider access

The manual list contains lrc.red, BiniLyrics, BetterLyrics, BetterLyrics Potato (Portato), PaxSenix, PaxSenix: Spotify, PaxSenix: Musixmatch, LyricsPlus, Unison, YouTube captions, YouTube Music, KuGou, LRCLIB and Musixmatch. Authenticated PaxSenix variants need an API key; direct Musixmatch needs an authorized developer key. Keys use Windows Credential Manager.

Direct YouTube sources require the current video's watch link/ID and use public endpoints; signed-in YouTube/OAuth access is not implemented. Automatic can use player metadata without a video link. Plain provider lyrics appear without invented synchronization, retaining closed-dock waveform fallback. Availability, regional restrictions and catalogue coverage vary; an adapter does not guarantee lyrics for every track.

## Install and update

Use x64 Setup for Intel/AMD PCs and ARM64 Setup for Windows on ARM. Both target Windows 10 build 19041+ and Windows 11. Portable ZIPs, all dependency notices and SHA-256 checksums accompany the installers. The .NET runtime is bundled; installers are unsigned.

Upgrades preserve existing settings, credentials, models and personal content. Original script remains the default for new installations. GitHub's latest published release is used by the existing update checker.

Windows 11 x64 is exercised locally. Physical Windows 10 and native ARM64 execution are not validated; ARM64 is cross-compiled and structurally checked. Managed local speech engines retain their separate architecture/CPU requirements.
