# NabyScape 2.22.0 — simpler navigation, your microphone, your install folder

- Panel navigation always uses dots. Existing icon/text preferences and imported layouts migrate to dots; app-launcher icons remain available.
- Choose an input microphone directly in Settings → Naby AI → Voice. The saved device is used by local voice, realtime voice, wake word and speech checks. Missing or ambiguous devices show an actionable error instead of silently using another microphone.
- Test microphone displays input levels during a four-second local check. Cancel stops the check; wake listening releases the device for testing and resumes afterward if previously armed.
- New installations default to `%LOCALAPPDATA%\Programs\NabyScape`. Setup includes a folder field and Browse button for a dedicated NabyScape folder on a writable local drive.
- Interactive setup can move legacy installations. Silent upgrades preserve the registered location; `--install-dir` specifies another destination. Shortcuts, startup entries, uninstall registration and updates follow the installed location.
- Uninstall preserves preferences and unrelated files in the chosen folder. Recovery avoids launching old installers that ignore custom directories.
