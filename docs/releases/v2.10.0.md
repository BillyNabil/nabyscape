# NabyScape 2.10.0

A more precise, calmer dock, with the accumulated local improvements since public 2.7.8.

## Your desktop, placed your way

- Position map with drag, center guides, numeric percentage and pixel coordinates, sliders and Center action. Native dock dragging snaps near horizontal center; a notch can snap back to the top edge.
- Follow-cursor monitor changes slide smoothly. Configurable duration, no focus stealing, reduced-motion support, and no movement timer while idle.
- Widget order uses drag-and-drop grips with keyboard Alt+Up / Alt+Down. Hover follows all active widgets and their order by default; a separate customizable hover deck remains available.
- Hover adds Weather, clock, volume, battery, shortcuts, Keep awake and Clean links. Existing media, timers, notes, shelf, clipboard, tasks, calendar and system previews remain available.

## A calmer daily view

- Compact weather card with day/night artwork, next hours, rain, humidity and wind. Sunrise/sunset are available in the forecast tooltip. City and units remain editable in Weather Settings.
- Clipboard selection actions stay above the independently scrolling history. Item previews appear first.
- Closed-dock ambience has its own switch. Tucked stays black. Single colors, cover blends, custom blends, direction, balance, reach and softness are available.
- Searchable Settings, clear category groups, friendlier labels, optional previews and collapsed advanced controls. Ambient preview stays visible while adjusting lower controls.
- Includes compact media disclosures, aligned transport/waveform, numeric duration controls, reset icons, refined Tasks and Naby composer, plus the original colored launcher icons.

## Efficiency and distribution

- Bounded thumbnail caching, shared audio measurement, retained motion resources and the earlier voice-buffer improvements.
- Cached hover-deck ordering rather than rebuilding it on every motion update; offscreen hover views collapse after their transition. Weather reuses the existing cache and updates while visible.
- Adaptive Auto performance is the fresh-install default. Existing preferences are not replaced.
- Updated actual-app silent film, README imagery, default layout and ambient website.
- Self-contained Windows x64 installer, portable package, notices and SHA-256 checksums.

## Validation scope

Compilation and packaging were completed. Tests and benchmarks were deliberately not run, per the user's instruction. The documentation film is a capture-only path with original sample content, a synthetic audio signal and an illustrative forecast. It is not a performance measurement. RAM usage and multi-monitor behavior have not been newly benchmarked for this release.
