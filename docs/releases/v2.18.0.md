# NabyScape 2.18.0 · local voice latency candidate

Local voice adds explicit stage labels and in-memory ASR / first-text / first-segment TTS durations, with detailed timing available in the voice tooltip. First-queued-audio timing excludes the silence-detection pause and hardware output delay. No speech content or timing telemetry is logged by this feature.

Supertonic, Kokoro and Kitten use one session-owned native worker with the pinned Sherpa 1.13.8 C ABI. The selected TTS model loads when voice starts and remains loaded until voice ends, including when the dock is closed. A current-user-only pipe carries bounded requests/audio, native libraries load in the worker rather than the UI, and the existing kill-on-close job owns native children. Active speech memory is additional to the dock process. Whisper retains its existing persistent ASR server; native Qwen/Moonshine ASR and legacy bundled Piper retain their previous loading paths.

Compatible Chat Completions endpoints can stream reply text into sentence-sized synthesis, with preparation and playback overlapping through bounded queues. Reasoning and named Hermes tool-progress events are excluded from speech. Locally offered tool turns buffer speech until the message is known to have no tool calls. Other protocols/image-output requests use the complete-response adapter; servers returning JSON to the same streaming request are supported. No automatic resend is used to recover agent requests. Streaming is enabled by default and can be disabled in Voice settings.

Speech chunks retain punctuation across deltas, recognize common sentence boundaries and skip fenced code. Spoken text/audio remain bounded; legacy Piper uses a complete spoken reply to avoid reloading the model per sentence. Captions follow queued playback. Stop cancels generation and clears queued audio; stalled playback and generation have deadlines. A failed spoken turn ends capture and shows an error. Interrupted text is marked partial rather than a completed agent result. The closed-dock reply panel can show the current spoken sentence, upgrading to the completed answer without repeating a dismissed notification.

Validation: source review, whitespace checks and Release compile/publish/package metadata only. No tests, UI automation, microphone activity, speech inference, wake recognition, provider/Hermes requests or latency/memory benchmarks were run, as requested. Native ABI loading, real SSE/provider compatibility, speech continuity and stop/device behavior remain unverified at runtime. This is a local candidate, not a claim of production readiness or measured latency improvement.
