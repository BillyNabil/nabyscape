# NabyScape 2.11.0 · local candidate

- Center media transport and waveform across the full player.
- Give Stopwatch its own panel so Timer and Focus stay visible together.
- Fit compact Weather into its panel budget without a small outer scroll.
- Allow a 0 px tucked edge, with screen-edge hover and shortcut recovery.
- Render basic Markdown headings, emphasis, lists, links, quotes and code as native WPF controls; no HTML or external image loading.
- Keep chat history in its own viewport and move session permissions into a bounded popover.
- Editable model picker, model discovery and Test connection with meaningful status and error notifications. The probe sends no user content.
- Optional Naby voice widget with a reactive character, audio halo, fading sentence captions and three conversation templates.
- Local turn-based ASR/TTS presets for light, balanced and approximately 8 GB VRAM setups. Windows voice, whisper.cpp, compatible ASR/TTS endpoints and an exportable faster-whisper bridge.

Local services and models are not installed automatically. Local speech uses the selected chat provider, which may be remote. See [setup and limits](../local-voice.md).

Compilation only; tests and real provider/audio/hardware checks were not run at the user's request. This candidate has not been pushed or published.
