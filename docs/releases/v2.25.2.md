# NabyScape 2.25.2 — smoother closed-dock lyrics

- The closed dock expands for longer lyric lines and returns to the saved width for shorter lines. Expansion stays within the existing screen-bounded host. Lines beyond that limit still use readable phrases. Saved dock dimensions are unchanged.
- Waveform and lyrics crossfade over 300 ms. Reversing a transition preserves its current opacity. Reduce Motion retains immediate changes.
- Brief blank gaps of up to one second between vocal lines keep the previous lyric visible. Explicit instrumental markers and longer breaks retain waveform fallback.
- TTML conversion no longer inserts blank end markers over overlapping vocal lines or short inter-line gaps. Original line timestamps remain intact, including in Romaji mode.

## Download and update

Use x64 Setup for Intel/AMD PCs or ARM64 Setup for Windows on ARM. Both target Windows 10 build 19041+ and Windows 11; the .NET runtime is bundled. Existing preferences, models and personal content are preserved. Portable packages, dependency notices and SHA-256 checksums accompany the installers. Installers are unsigned. Physical Windows 10 and native ARM64 execution are not validated; ARM64 is cross-compiled and structurally checked.

The previous release's multi-source lyrics, offline Japanese Romaji, language filtering and Power plan widget remain included. Provider catalogue coverage and language identification are not guaranteed for every track. The existing updater discovers the latest published GitHub release; downloads and installation follow the user's preferences.
