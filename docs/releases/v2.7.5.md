# NabyScape 2.7.5 · Cover ambient, interactions & Hermes

Local candidate; no GitHub release or website deployment is included.

## Cover ambient

**Appearance → Cover ambient** adds light from the bottom of the music surface, sampled from the actual album artwork. Adjust intensity and spread, then choose **Still**, **Breathe** or **Drift**. Other panels keep their dark surface. Black glass and the older album tint remain independent choices.

Color extraction uses a bounded 32×32 thumbnail once per artwork change. Continuous motion uses retained WPF brush clocks, follows the performance frame limit, and stops for pause, tuck, hide and Reduce motion. No separate polling or per-frame managed callback was added.

## Interaction feedback

**Appearance → Motion → Interaction feedback** offers **Off / Subtle / Expressive**. Buttons lift gently on hover, settle on press and support keyboard feedback. Cover art responds to hover; slider thumbs expand during interaction; Settings switches slide, task checks pulse, and expanded sections enter softly. Existing navigation, timers and island motion remain in place.

## Notifications

**Application → Notification presentation** adds **Lift / Fade / Soft scale**, a 4–30 second compact lifetime, a preview, scheduled quiet hours and 15/30/60 minute snooze. Quiet hours and snooze silence Naby completion sounds as well as notifications. Other apps' Windows notifications are unaffected.

Notification details show their type, title and queue count, with **Dismiss / Next / Clear all**. Incoming notices keep the current card intact. Details fit the working area and scroll when necessary; downloads retain original-file drag and shelf actions. The queue remains temporary and bounded to ten items.

## Hermes Agent

A dedicated Hermes Agent preset connects Naby chat to an existing Hermes API gateway. Sessions are isolated and rotate on Clear; admission keys are unique per request. Keys use the existing Windows credential storage. Hermes tools execute on the backend under Hermes permissions. Native Hermes gateway interoperability remains a manual check; fixtures verify the HTTP contract without a personal API key.
