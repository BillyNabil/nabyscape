# NabyScape 2.5.1

New installations now use **Daily Notch**, the maintainer's selected visual and interaction preferences:

- 327 × 36 closed notch, 526 px panel (417 px height limit), 447 × 207 hover preview.
- Black glass with white accent, artwork + waveform, bold headings and icon-only navigation.
- 420 ms motion, Maximum performance preset, wheel changes pages, maximized-window tuck and a 9 DIP edge.
- Six hover pages: Music, Timer, Focus, Calendar, Notes and Shelf. All main widgets are enabled in the selected order; detachable previews, the satellite and Activities start off.

The bundled [default layout](../presets/default-layout.json) contains visual/interaction preferences only. It includes no personal Notes, Tasks, clipboard history, files, application targets, download folders, monitor identity or startup consent. Clipboard capture, startup and download watching remain opt-in.

Existing settings and legacy-profile migration are preserved. No upgrade rewrites a user's saved layout. Explicit preference reset now uses Daily Notch, retaining personal content and existing startup/clipboard choices. Existing installations can import the layout deliberately from Settings → Layout.

Includes all [v2.5.0 features and interaction fixes](v2.5.0.md). Windows 11 x64; runtime included. Installer remains unsigned. Installer, portable ZIP, notices and SHA256SUMS are attached to the release. The default layout is also available as an optional download.
