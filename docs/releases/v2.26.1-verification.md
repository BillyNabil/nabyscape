# NabyScape 2.26.1 verification

On 7 November 2026, the local Windows 11 x64 release executable passed **all 576 logic tests**, together with the Settings scene registry and uninstall-plan checks. New tests cover quiet-hours handling for other apps, test notifications (always shown on the dock, sent to Windows when the dock is hidden), banner lifetime bounds, one-time banners and stable avatar initials and colours.

The notification-center integration suite runs in an isolated profile and now covers:

- a new alert opening the dock banner without a click, naming the sender and showing the message;
- the banner folding back on its own and the next queued alert following;
- the dock returning after the last banner while alerts stay in the center;
- **Send test notification** opening a banner during quiet hours;
- the center fitting inside the dock host and matching **Panel width** exactly.

Settings gallery, Settings matrix, Stage 2, premium, production UI, recent UX, minimal widgets, interaction tuck/hide, hover responsiveness and welcome suites pass. One integration preview check fails identically on earlier releases on this machine. A premium Audio-heading check failed temporarily on both 2.26.0 and this build during one session and passed again later; it depends on the live media session.

The release executable was installed locally over 2.26.0; its hash matched the build and the application restarted without new errors. Real app logos depend on what Windows provides for each sender; alerts received before the update show initials. Public packages are rebuilt from the tag by GitHub Actions, which verifies both PE architectures, executable identity, WinGet metadata, asset hashes and all nine notices.
