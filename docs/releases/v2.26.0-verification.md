# NabyScape 2.26.0 verification

On 7 November 2026, the local Windows 11 x64 release executable passed **all 569 logic tests**, together with the Settings scene registry and uninstall-plan checks. New tests cover the notification history, mirrored alerts from other apps, popup ownership for island drop-downs, the taskbar/own-window tuck rule and work-area detection. A local run of the release packaging script built x64 and ARM64 and passed its hash, architecture, WinGet metadata and nine-notice checks.

Integration checks run in isolated profiles:

- **Settings gallery** renders every category in the essentials view, checks the essentials filter, search reveal and Show all settings, and lays out at 640 and 480 DIP.
- **Settings matrix** (1024×600 to 1920×1080 at 100–200 % scaling) keeps every control inside the viewport and reachable by scrolling.
- **Notification center** (15 checks) covers the bell, ordering, live arrivals while open, removal, mirrored alerts with their sender, hidden message text and a real read of Windows' notification list from inside NabyScape (eight apps found; names only).
- Stage 2, premium, production UI, recent UX, minimal widgets, interaction tuck/hide and welcome suites pass.

Pre-existing failures that reproduce identically on the unmodified 2.25.3 source remain: integration idle preview fallback, Stage 4 and premium-experience scene lookups, Stage 6 material scene and UX completion selector. They concern diagnostic fixtures, not the changes in this release.

Live arrival of a third-party notification was not exercised automatically: Windows does not let an unpackaged app raise or subscribe to another app's notifications, so the watcher compares snapshots and its timing was reviewed in code. The final executable was installed locally over 2.25.3; its hash matched the build and the application restarted without new errors. Public packages are rebuilt from the tag by GitHub Actions, which verifies both PE architectures, executable identity, WinGet metadata, asset hashes and all nine notices.
