# NabyScape 2.25.2 verification

On 1 November 2026, local Windows 11 x64 verification passed **539 logic tests** and **16 closed-dock checks**. The final executable was installed locally and its SHA-256 matched the installer. The installed application restarted successfully.

The dock checks cover dynamic lyric width, bounded expansion, restoration of the saved width, intermediate waveform/text opacity, explicit instrumental sections, short timestamp gaps, timer priority, paused playback and reduced motion. These are automated state/layout checks, not a claim of measured GPU-presented FPS or identical appearance on every display.

Public release packages are rebuilt from the release tag by GitHub Actions. Packaging verifies both PE architectures, setup/portable executable identity, WinGet metadata, all five release-asset hashes and all eight notices. ARM64 is cross-compiled; physical Windows 10 and native ARM64 runtime behavior remain unverified. Existing provider availability and generated-pronunciation limitations apply.
