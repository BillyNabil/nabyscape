# NabyScape 2.23.0 — a complete setup, a complete cleanup

- New installations use a complete daily preference snapshot instead of only a layout export. Appearance, animation, lyrics, notification routing/quiet hours, clipboard history, download alerts and companion availability follow the selected setup. Private shortcuts, provider connections, file paths, weather location and device IDs are excluded.
- Recommended is selected in onboarding. Returning to it restores the complete starting widget selection after trying a purpose preset.
- Startup is an explicit installer checkbox, selected for a fresh recommended installation. Silent upgrades preserve existing startup choices. Update checking is on; automatic update downloads are off in the selected snapshot.
- Uninstall is available directly in Settings → General and through a Start menu shortcut, alongside Windows Installed apps.
- Complete cleanup is selected by default: managed ASR/TTS models and engines, settings/history, preserved legacy profiles, downloaded updates/rollback files, app-specific caches and saved NabyScape API keys. Uncheck the option to keep data for reinstalling. Quiet uninstall also supports `-KeepData`.
- Imported models outside NabyScape and shared Windows components are kept. Dedicated roots and every planned file are checked before deletion; links/junctions are rejected instead of followed.

Existing preferences are preserved on upgrade. To reinstall with the new defaults, choose complete cleanup when uninstalling first; otherwise your intentionally retained preferences will be reused.

Windows x64 and ARM64 packages target Windows 10 build 19041+ and Windows 11. Installers are unsigned. Native Windows 10/ARM64 execution and live profile/credential removal still require device/system integration testing.
