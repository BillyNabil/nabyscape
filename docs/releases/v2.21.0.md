# NabyScape 2.21.0 · bounded preview memory

Local candidate; not published.

Screen-sharing image encoding avoids full-frame managed copies for opaque frames. Mixed-alpha frames retain the previous alpha-weighted JPEG output through a zero-copy native bitmap view. Base64 validation no longer allocates a decoded payload just to validate it. These reduce transient managed allocations; they do not represent an equivalent reduction in total process RAM or GPU memory.

Chat attachment previews decode only near the visible viewport, preserve layout independently of loaded pixels, and share a session-scoped thumbnail cache bounded to 12 entries / 8 MiB with idle expiry. Preview pixels detach from encoded streams. Original image/file contents remain available to copy, save, enlarge and send. Remote previews still reauthorize each read; invisible attachments are not fetched to discover their dimensions.

Regression fixes include General settings illustrations, nullable weather-location preference restores, language/accessibility normalization and save rollback, and empty provider selections remaining disabled after cancellation. Update-test staging and WPF diagnostics use isolated folders and instance names.

Validation details and resource measurements are recorded in [performance and local acceptance](../performance-2.21.md). Synthetic local tests do not certify every Windows version, physical monitor/DPI transition, speech engine, external provider, codec or ARM64 device.

The compact media source disclosure stays within the dock viewport, including small panels. None hides media activity without pausing playback; Auto restores Windows source selection. New profiles have a short, skippable setup guide with optional AI setup, reopenable from General settings.
