# 2.11.1 · Chat space and voice setup

Local update; not published to GitHub.

- Naby chat opens at a dedicated 720 × 680 DIP target, bounded by the selected screen. Existing larger panel preferences are respected. The composer is smaller so long replies have more room, while the transcript scrolls independently.
- A labeled **Voice mode** button opens the voice widget without starting the microphone. The voice room has a separate 520 × 540 DIP target to leave room for its controls.
- **Choose ASR & TTS** jumps directly to voice setup. The setup explains ASR and TTS, offers hardware presets and editable suggested model/voice choices, and puts server addresses and microphone tuning behind an advanced section.
- Local service instructions, connection feedback and save confirmation appear together. Suggested models are not presented as installed models. Local speech servers still need separate installation and startup.

Compilation/package only. No automated tests, UI trial, microphone/speaker trial, provider requests, model downloads or benchmark was run at the user's request.
