# NabyScape 2.5.0

A smoother island, more useful local tools, and clearer settings.

## Interaction fixes

- Hover pages follow their own enabled list, independently of main-panel visibility. Tool-specific switches still apply. No four-slide limit, and no forced clipboard capture.
- Automatic and manual tuck animate from the current position, reverse smoothly, respect Reduce Motion, and stop immediately when manually hidden.
- The audio mixer resolves local application icons with a compact initials fallback, larger mute glyphs, and corrected Music → mixer → Back navigation in classic layout.

## New tools and preferences

- Responsive Settings, separate Notes and Tasks pages, and a clean idle island.
- Validated migration to `%LOCALAPPDATA%\NabyScape`, preserving the legacy folder; backed-up category/all preference reset and restore without deleting personal content or changing startup.
- Always tucked, an adjustable 3–12 DIP edge, and configurable Ctrl+Alt+T manual tuck.
- Official-release update checks; downloading and installation require your action. Compatible version, source and checksum are verified.
- NabyScape notifications with Notch / Windows / Both / Off routing. No reading of other apps' notifications.
- Opt-in Downloads Activity: watches one folder for stable, readable new files. Drag out, reveal in folder or add to shelf. It does not prove a browser download completed.
- Stopwatch and Primary / Selected / Follow cursor placement. Relocation waits during interactions.
- Optional native Mica/Acrylic for Settings on supported Windows 11 systems, with visible Solid fallback. The island retains its existing material.

## Downloads and upgrading

Windows 11 x64; self-contained .NET runtime included. Use `NabyScape-win-x64-Setup.exe` or extract `NabyScape-win-x64-Portable.zip`. `SHA256SUMS` covers the installer, portable archive and third-party notices. Upgrade preserves local content and startup preference. The installer is unsigned; Windows SmartScreen may still warn. No code-signing or Microsoft Store trust is claimed.

## Verification and limits

The local packaged build passed 379 logic checks and 49 Settings scene registrations. Focused desktop runs passed 60 interaction checks, 3 animated-hide checks and 6 classic mixer navigation checks. The local hotfix was applied with an executable/settings backup; the installed hash, settings and startup preference were verified. Release packaging independently validates hashes, archive contents and notices.

Original gallery and silent film are labeled v2.4.2. The Settings capture is v2.5; fixture media uses sample data. Physical mixed-DPI hotplug, every protected application's icon, hardware sleep and code signing are not established by these checks. See [integration evidence](../verification-2.5.0.md) for the earlier broader matrix and its limitations. This release does not claim new performance percentages.
