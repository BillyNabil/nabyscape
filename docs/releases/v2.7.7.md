# NabyScape 2.7.7 · Quieter widgets

The seven everyday widget pages use more deliberate spacing, larger visual anchors and fewer persistent controls while retaining the black island silhouette and existing navigation.

- Music places larger artwork beside the title and compact transport, with an understated source selector.
- Timer and Focus use thin progress rings and a single Start, Pause or Resume action.
- Launch keeps real application icons and a lighter command-search field.
- Tasks adds a completion ring, open checklist rows and a bottom composer.
- File shelf presents real thumbnails with selection and drag-out support.
- Smart clipboard presents content previews in two columns, falling back to one on narrow docks. Copy, original image export, pinning and removal remain available.
- Calendar adds a seven-day strip and a compact agenda. Month navigation, local event editing and meeting links remain available.

Secondary shelf, clipboard and event actions are available through keyboard-accessible menus. Open menus keep the island available and defer cursor-follow movement. Image decoding is limited to the nearby scroll viewport and released when leaving the gallery.

This update does not change saved preferences, provider credentials or personal content. Windows shell thumbnail support varies by file type and installed thumbnail provider.
