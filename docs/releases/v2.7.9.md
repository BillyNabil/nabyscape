# NabyScape 2.7.9 · Runtime and rendering efficiency

This update reduces runtime memory while keeping the existing interface, animation settings and features.

- Runtime assemblies remain file-backed instead of being decompressed from the single-file bundle into private memory. The portable ZIP still compresses delivery; the installed executable and self-installing EXE are larger.
- The existing waveform renderer, 25 bands, attack/release, sensitivity, dimensions and rounded bars are retained. FFT band bounds are precomputed without changing their values.
- The companion's idle breathing, float and sway share one retained animation clock, with the original curves and periods. Hover, pointer tracking, blinking, headphone and live states remain available.
- Shelf and Clipboard share one bounded display-image cache with LRU eviction and idle expiry. Portrait previews decode by their long edge to avoid oversized textures. Visible previews retain their images; Copy and Save use originals.
- Voice playback storage grows with queued audio and releases on Clear or session disposal. The existing two-minute limit, ordering, interruption generation and silence-fill behavior remain intact.
- Shared frozen easing functions, reused character drawing resources, cached audio endpoint IDs, precomputed FFT band bounds and screen-image conversion avoid repeated work.

Saved preferences, content, startup configuration and provider credentials keep their existing formats. The renderer's frame policy and animation detail are unchanged. No periodic forced garbage collection or working-set trimming is used.
